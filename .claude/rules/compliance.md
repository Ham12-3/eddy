# Compliance documents

- Edit these files only when the user has explicitly asked for that edit. A permission rule asks them every time.
- Never claim evidence, tests or sign-off that do not exist. "Not started" is an acceptable status; an invented one is not.
- Link each claim to the SPEC.md section, test file or evidence block it relies on.
- Copyright advice and lawful-basis wording are proposals until a legal reviewer signs them off. Say so.
